        What I learned

        Activity Reflections

        01 – Ralph Lauren Collection Website

        Building this multi-page website taught me how to plan a site’s structure and keep a consistent design across several pages. I learned to link pages together with navigation, organize content using semantic HTML, and style layouts with CSS so the site looks clean and professional. It also showed me how important images, spacing, and typography are in making a brand’s website feel polished.

        02 – Event Handling Profile Card

        This activity introduced me to JavaScript event handling. I learned how to make a page respond to user actions such as hover, click, double click, and press and hold using event listeners like mouseover, click, dblclick, and mousedown/mouseup. I also practiced updating the status message through the DOM and using CSS transitions to make the profile photo grow on hover. It helped me understand how a webpage can feel interactive instead of static.

        03 – Interactive Student Profile

        Through this project, I learned how to build a page that collects and displays information using interactive controls, dropdown menus, buttons, and tables. I practiced connecting HTML elements to JavaScript functions so that selecting a program or clicking a button changes what is shown on the page. It strengthened my skills in DOM manipulation, organizing data in tables, and designing a clear, user-friendly interface.
